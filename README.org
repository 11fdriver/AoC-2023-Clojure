* Advent of Code 2023 in Clojure

Solutions to [[https://adventofcode.com/2023]] written in the [[https://clojure.org/][Clojure]] functional Lisp programming language, mirrored from a local [[https://fossil-scm.org/][Fossil]] repo. It is developed in [[https://www.gnu.org/software/emacs/][GNU Emacs]] with [[https://cider.mx/][CIDER]].

* How to run

#+begin_src shell
$ git clone ...			# Clone repository
$ cd aoc-clj-23			# Project root
$ clj -X:solutions		# Run aoc-23.main/-main
#+end_src

*Requirements*:
- Clojure 1.11.1+

=clj -X:solutions= will load, run & print all completed solutions.

* Get puzzle inputs

*Requirements*:
- [[https://babashka.org/][Babashka]]
- Your AoC session cookie.

Session cookie in Firefox: =right click > Inspect > 🗄 Storage > Cookies=.

Session cookie in Chromium: =right click > Inspect > Network > Cookie=.

Place this into a file named =.aoc-23-session-cookie=. Note that the format should be ~session=a1b2c3d4...e5f6h7i8~.

Run =bb get-input 1= to get the first day's input. (The script is simple; see =bb.edn= for reference).

The script will cache inputs into the =input= directory, and won't overwrite pre-existing files.
